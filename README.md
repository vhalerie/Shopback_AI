Instructions on how to use the prototype:

The prototype simulates a mobile screen. All interactions are tap/click-based.

**1. Home Tab — Cashback Tracker Widget**

On load, you'll see the ShopBack Home tab with the new Cashback Tracker widget inserted below the category tabs.

Tap "4 items in progress ›" on the Pending pill → opens the full My Cashback activity list
Tap "See all ›" → opens the same My Cashback activity list
Tap "Redeem" on the Available Cashback pill → placeholder (not wired in this prototype)

**2. Cashback Items — Two States Demonstrated**

Charles & Keith (Online purchase)

Shows the online cashback lifecycle: Tracked → Validating → Confirmed → Received
Currently in Validating state — merchant validation est. 60–90 days
Tap the card to view the full detail screen with timeline

Food Republic — Raffles City (In-store)

Shows the in-store cashback lifecycle: Tracked → Confirmed → Received
Currently in Tracked state — user needs to return to the merchant to confirm
Tap the card to view the full detail screen with expiry warning
Tap "Pay now →" to proceed to the QR scan screen

**3. My Cashback Activity List**

Accessible via "See all ›" or the Pending pill. Shows all pending cashback items grouped by date, faithful to ShopBack's existing My Cashback screen — with the addition of a Validating status for online items and urgency indicators for expiring in-store cashback.

Tap ‹ to return to Home

**4. Cashback Detail Screen**

Accessible by tapping any cashback item card on the Home widget.

Shows full lifecycle progress bar with current stage highlighted
Shows timeline with dates and estimated validation windows
For in-store items: shows a "Pay now →" CTA that opens the QR scan screen
